Keep each child’s routine clear

Siblings rarely have exactly the same jobs. Separate child profiles make it easier to give each child a list that suits their age, schedule and responsibilities.

Everything stays together on the parent’s device. You can manage the whole family routine without creating email addresses, passwords or independent logins for children.

The profile is there to separate one child’s routine from another, not to create another account for the family to maintain. Parents can change that child’s chores and rewards independently while still managing the wider household from the same parent-controlled setup.

Only add what the family needs. A first name or nickname is usually enough to make each child profile easy to recognise.

Quick questions

What can be kept separate inside each child profile?

Each child profile can have its own chores, approved progress and reward activity so siblings do not need to share one mixed list or total.

Does creating a child profile create a separate login?

No. A child profile remains part of the parent-managed family setup and does not require an independent email address, password or child account.

What information should I put in a child profile?

Parents only need to enter the information useful for their own family routine. A first name or nickname can be enough to tell the profiles apart.
