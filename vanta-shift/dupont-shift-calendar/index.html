Quick questions

What is dupont shift calendar useful for?

It helps you generate months of working and rest days from one starting date using the common rotating rota stored on your device.

Does it work for night shifts?

Yes. Start and finish times can cross midnight so overnight work remains clear in the calendar.

Does dupont shift calendar manage other people?

No. Vanta Shift is a personal shift planner for the individual using the app.
