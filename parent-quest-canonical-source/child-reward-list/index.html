Child Reward List

Create a clear reward list for each child, with choices that match their interests rather than somebody else’s.

Give each child something meaningful to aim for

Siblings are not always motivated by the same things. A shared family treat might work for everyone, while personal rewards may need to be different for each child.

Separate child profiles help keep those choices organised. Parents can see each child’s available rewards and progress without mixing balances, tasks or goals together.

Reward lists stay under parent control. Children can see what they are working towards, while changes to rewards remain protected by the parent PIN.

Quick questions

Who creates the rewards?

The parent or guardian creates and provides every reward.

Are rewards supplied by Vanta Labs?

No. Vanta Labs does not fund, supply or guarantee family rewards.

Can rewards be changed?

Yes. Parents can change the reward list as the family’s interests and circumstances change.
