A child-friendly routine with adult control

Children can see and mark the jobs in their own profile without being able to rewrite the routine or approve their own progress.

The parent manages everything from the same device, using the Parent PIN for protected actions such as approval and reward changes.

Children can therefore follow the routine without controlling the rules behind it. The parent can change which chores appear each day, review submitted work and manage reward decisions while the child-facing side remains focused on the jobs themselves.

Protected actions stay with the adult. Keep the Parent PIN private so children cannot approve chores or change the family reward setup.

Quick questions

Can the parent decide which chores appear each day?

Yes. The parent controls the daily routine and can keep some chores regular while using others only when they are relevant.

Can each child have a different parent-managed daily routine?

Yes. Separate child profiles can contain different chores and expectations while remaining under the same parent-controlled setup.

Can children approve their own daily chore progress?

No. Children can mark work complete, but the parent or guardian keeps the protected approval step.
