Quick questions

What is work rotation calendar useful for?

It helps you place a complete working cycle across the calendar quickly using the repeating shift pattern stored on your device.

Does it work for night shifts?

Yes. Start and finish times can cross midnight so overnight work remains clear in the calendar.

Does work rotation calendar manage other people?

No. Vanta Shift is a personal shift planner for the individual using the app.
