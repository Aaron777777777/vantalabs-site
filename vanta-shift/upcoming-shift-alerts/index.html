Quick questions

Can I get alerts for shifts coming up in my calendar?

Yes. Personal reminders can be set around saved shifts to help keep upcoming working dates and start times visible.

Can I use this with rotating work?

Yes. The calendar supports repeating day, night and off patterns as well as individually entered shifts.

Does upcoming shift alerts manage other people?

No. Vanta Shift is a personal shift planner for the individual using the app.
