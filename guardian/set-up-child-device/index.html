How to set up a child's phone with Guardian

Setting up a child device starts with making sure Guardian is being configured on the phone the child will actually carry. That phone is the device Guardian relies on for the child-location information available to the family.

A practical child-device setup checklist

The child device should be the compatible phone your child actually carries. Guardian uses that device's available location and status information to support the private Family Map and Home and School alerts.

Set up and test together

  1. Prepare both phones: Make sure the parent and child devices have a working internet connection and install Guardian using the appropriate store links above.
  2. Connect the family: Follow Guardian's on-screen family and child-device connection steps. Check that the intended child phone is linked to the correct family.
  3. Check permissions on the child phone: Enable location services and review the location access that Guardian requests. Background location access may depend on the phone and operating system.
  4. Check notifications and battery settings: Allow relevant notifications and inspect any power-saving restrictions that could interrupt background reporting.
  5. Confirm the first update: Open the Family Map on the parent device and look at the latest reported location and last-update time. Allow for normal GPS and network variation.
  6. Test a routine alert: Configure Home or School in Guardian, then test an arrival or departure alert together rather than assuming notifications will always arrive instantly.

What to do if setup seems incomplete

Check that the correct phone is connected, its location permission remains enabled and it can use mobile data or Wi-Fi. Settings may differ between Android and iPhone. If updates stop later, use our location-not-updating checklist.

Learn more about Home and School safe zones or how Guardian works. Set expectations with your child and use Guardian openly as part of normal family communication, not as an emergency service.

Guardian is not an emergency service. Location and notifications can be affected by GPS, connectivity, permissions, battery settings and operating-system restrictions.

Quick questions

Which phone should be used when setting up a Guardian child device?

Use the phone the child will actually carry, because that connected device is the source of the child-location information Guardian can receive.

What phone settings matter after a child device is connected?

Location permissions, background behaviour, connectivity and battery restrictions can all influence whether the phone continues reporting normally.

What should parents check if the child device later stops updating?

Check the phone’s permissions, connectivity, battery state and background restrictions before assuming the displayed location reflects the child’s current movement.
