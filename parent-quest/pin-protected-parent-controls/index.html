Use the Parent PIN to protect approvals and family settings while keeping the everyday child view simple.

Put a clear boundary around parent actions

A shared device works best when children can use the routine without having access to every setting. The Parent PIN separates normal task use from actions that should remain adult controlled.

Parents can enter the protected area when they need to review progress or manage the setup. Children can still see their own tasks and rewards without being able to rewrite the rules.

This makes the shared-device model much clearer: normal child use does not need access to the same controls used to change family settings. The parent can step into the protected area when necessary and then return the device to the child-facing routine.

Choose a PIN children do not know. The protection only works properly when the Parent PIN remains private.

Quick questions

Which actions are separated by the Parent PIN?

The PIN separates protected parent actions such as approval and family management from normal child-facing task use.

Can children access parent-only approval controls?

No. Those controls are intended to remain protected for the parent or guardian.

Are PIN-protected controls meant to create a complicated workflow?

No. The protection creates a clear adult boundary, while everyday task use and approval are kept as straightforward as possible.
