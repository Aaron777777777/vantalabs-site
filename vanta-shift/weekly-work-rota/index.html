Quick questions

What is weekly work rota useful for?

It helps you check upcoming work without searching through screenshots or messages using the personal rota stored on your device.

Does it work for night shifts?

Yes. Start and finish times can cross midnight so overnight work remains clear in the calendar.

Does weekly work rota manage other people?

No. Vanta Shift is a personal shift planner for the individual using the app.
