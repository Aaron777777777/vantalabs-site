Shared Family Task Screen

Use a shared family screen for chores and progress while keeping important changes protected from the child-facing view.

Google Play App Store

Make one screen useful for the whole household

A shared task screen works best when each child can quickly find their own profile and see what needs doing. It should feel clear enough to use without the parent explaining every step.

When it is time to approve work or change the setup, the parent enters the protected controls. This keeps normal family use simple while preserving a clear adult boundary.

One screen can therefore serve different purposes depending on who is using it. Children can find their own profiles and tasks, while the parent can move into the protected controls when something needs approving or changing.

Shared use does not mean shared authority. Children can use the routine, but protected decisions remain with the parent.

Quick questions

Does every child need a separate screen or phone?

No. A shared parent-owned device can provide access to separate child profiles and task lists.

Do children need accounts to use the shared family screen?

No. They use child profiles inside the parent-managed family setup rather than separate email accounts.

Who can change settings from the shared task screen?

The parent or guardian controls protected settings, approval and rewards rather than leaving those actions in the child-facing view.
